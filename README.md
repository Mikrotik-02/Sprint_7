# Sprint_7

## Описание проекта

Автоматизированное тестирование API сервиса Яндекс Самокат.

Покрытые сценарии:

* создание курьера;
* логин курьера;
* создание заказа;
* получение списка заказов.

## Стек технологий

* Python
* Pytest
* Requests
* Allure

## Структура проекта

* `api/` - API-клиенты для работы с ручками сервиса.
* `data/` - тестовые данные для запросов.
* `helpers/` - вспомогательные функции и генераторы тестовых данных.
* `tests/` - API-тесты.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```

## Генерация Allure-результатов

```bash
pytest --alluredir=allure_results
```

## Просмотр отчёта

```bash
allure serve allure_results
```
